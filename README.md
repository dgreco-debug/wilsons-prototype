# Wilson's of Redmond: website prototype

Clickable prototype for internal review. Shows 29 real in-stock items with prices and quantities from the 10/24/2026 inventory export.

- Checkout, accounts and reservations are simulated.
- Product text and images come from the store's current web catalog and manufacturers' sites. They must be rewritten and permissions confirmed before any real launch.
- No customer data or costs are included.

Built from `prototype/` in the Command Center project (`build_data.py` regenerates `index.html`).
